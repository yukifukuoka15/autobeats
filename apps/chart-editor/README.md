# AutoBeats 譜面エディター（apps/chart-editor）

MP3 / WAV / M4A / OGG を読み込み、完全オフラインのローカル音響解析で BPM・拍・オンセット・曲構成・サビ候補を推定し、LEVEL 1～4 の譜面を個別生成・編集して、ネオンヒット（高専祭ゲームアプリ）用の `chart.json` + 音声フォルダを書き出す Windows / macOS 用 Electron アプリです。高専祭ゲームアプリとは別に起動・ビルドできます。

「AI自動解析」ボタンの実体は純粋 TypeScript のローカル音響解析（`packages/audio-analysis`）です。精度は 100% ではなく音源によって変わるため、結果は必ず試聴して手修正してください。

## 起動・ビルド

リポジトリのルートで依存関係をインストール済みであること（`npm install`）。

| 目的 | コマンド（ルートで実行） |
| --- | --- |
| 開発起動（エディターだけ） | `npm run dev:editor` |
| 本番ビルド（`apps/chart-editor/out/`） | `npm run build -w apps/chart-editor` |
| ビルド済みを起動 | `npx electron apps/chart-editor/out/main/index.js` |
| Windows 向けパッケージ | `npm run package:win:editor` → setup.exe / portable.exe |
| macOS 向けパッケージ | `npm run package:mac:editor` → `apps/chart-editor/release/mac-arm64/AutoBeats Chart Editor.app` |
| 型チェック | `npm run typecheck -w apps/chart-editor` |
| Lint | `npx eslint apps/chart-editor` |
| Unit テスト | `npx vitest run --project chart-editor` |
| Integration テスト | `npx vitest run --project integration` |
| E2E（Playwright + Electron） | `npm run test:e2e -w apps/chart-editor` |
| テスト用合成音声の生成 | `npm run fixtures` |

パッケージは署名なし（`identity: null`）です。配布時は `electron-builder.yml` の `mac.identity` を設定して署名・公証してください。YouTube取り込み用のPython実行環境・yt-dlp・FFmpeg・Denoを同梱します。配布版の利用者による追加インストールは不要です。

## アプリアイコンとインストール

- アイコンはピクセル調（黒背景・二重線の枠・中央に音符）で、`python3 scripts/make-icon.py apps/chart-editor/resources <アクセント色>` が `resources/icon.png` と iconset を生成し、`iconutil -c icns` で `resources/icon.icns` を作ります（外部素材なし）。
- `npm run package:mac:editor` のあと `ditto "apps/chart-editor/release/mac-arm64/AutoBeats Chart Editor.app" "/Applications/AutoBeats Chart Editor.app"` で Launchpad／アプリケーションフォルダに表示されます。未署名のため初回は右クリック →「開く」が必要な場合があります。

## デザインとプレイテスト

- 見た目はメインアプリ（LED ボタンアーケード）と同じ「1980 年代 迷路型アーケード」意匠です。黒背景、赤の二重線の枠（メインアプリの青を赤に置き換え）、黄色いペレット、硬い影、ピクセルフォント（Press Start 2P / DotGothic16、いずれも SIL OFL 1.1、`src/renderer/src/assets/fonts/` に同梱）。レベル色は黄・水色・桃・橙です。
- 上部の「プレイテスト」（`Cmd+P`）で、ゲーム画面と同じレーン表示（球が右から左へ 3000ms で流れ、判定枠で判定）を使って 4 レベルを同時に試奏できます。ボタンは **LEVEL 1 = Q または スペース、LEVEL 2 = W、LEVEL 3 = O、LEVEL 4 = P**。3 秒のカウントダウン後に再生ヘッド位置（または曲頭）から始まり、判定幅・得点・コンボはゲームと同じ共通ルール（PERFECT ±80 / GOOD ±160 / BAD ±220ms、100/50/10/0 点）です。入力遅延補正を試せます。Esc または「中止」で終了し、編集データ・Undo・未保存状態には影響しません。

## 楽曲ライブラリ（アプリ内保存）

- 楽曲を読み込んだ時点で、音声ファイルのコピーが `~/Library/Application Support/@autobeats/chart-editor/library/<id>/audio.<ext>` に保存されます（`<id>` は音声の SHA-256 先頭 16 文字。同じ音声は 1 件にまとめます）。原本は読むだけで変更・移動しません。再生・解析・書き出しはこのコピーを使うため、元ファイルを移動しても開けます。
- 保存（`Cmd+S`）と自動保存のたびに、最新の譜面データが同じフォルダの `project.json` へ写され、左パネル最上部の「ライブラリ」に曲名・長さ・BPM・各レベルの音符数・更新日時が一覧されます。「開く」でその楽曲と譜面を再度開き、「削除」でアプリ内のコピーと譜面データだけを削除します（原本と `.rhythm-project.json` は残ります）。

## 用語

ボタンを押すタイミングを **ヒット** と呼びます（JSON では `notes[]` / `hitAtMs`）。連打は `type: "mash"` と `durationMs`（区間の長さ）を持つヒットです。プレイテストとゲーム判定では、連打区間内の押下 1 回ごとに +10 点、区間終了時に押下回数で PERFECT（200ms に 1 回以上）/ GOOD（その半分以上）/ BAD（1 回以上）/ MISS（0 回）を確定します。

## 画面構成

- 上部: プロジェクト名、保存状態、「楽曲を読み込む…」「AI自動解析」「保存」「ゲーム用に書き出し…」、Undo / Redo
- 左: 楽曲情報（ファイル名・形式・サイズ・長さ・サンプルレート・チャンネル・SHA-256）、プロジェクト情報（曲名・アーティスト・楽曲ID・BPM・オフセット）、解析結果、レベル別の密度・最小間隔・サビ密度倍率・拍スナップ強度と表示切替
- 中央上: 現在時刻 / 総時間、BPM、先頭・再生/一時停止・停止・末尾、ループ、メトロノーム、試聴音、再生速度（0.5x / 0.75x / 1.0x / 1.25x）、原曲・メトロノーム・試聴音の音量
- 中央: ルーラー → サビ区間ストリップ → 波形 → LEVEL 1 → LEVEL 2 → LEVEL 3 → LEVEL 4 の順のタイムライン（Canvas、Retina 対応）
- 右: スナップ設定、選択中の音符（hitAtMs の数値入力、生成理由、±1/±10ms、削除）またはサビ区間（開始・終了の数値入力、削除、ループ範囲にする）、リアルタイム検証（同一レベル内の完全重複・最小間隔違反、難易度間の 80ms 以内の衝突（組み合わせ別件数）、範囲外、不正 ID、非整数。一覧クリックで該当位置へ移動。衝突時は「衝突している音符だけ修復」「4レベルを再生成」）
- 下部: ズーム、横スクロール、解析進捗とキャンセル、状態メッセージ、各レベルの音符数

## 操作とショートカット

| 操作 | 方法 |
| --- | --- |
| ヒット（ボタンを押す位置）を追加 | レベルレーンをダブルクリック、または `J`（`N` / `Enter` も可）で編集中レベルの再生ヘッド位置へ。再生中にタップしても追加できる。他レベルのヒットと 80ms 以内で衝突する位置なら、最寄りの空き位置（スナップ候補のうち最小間隔も満たすもの）へ追加して理由を表示する |
| 連打を追加 | `F` を押している間（再生中なら再生ヘッドが進んだ区間、停止中なら矢印スクラブで動かした区間）。離した時点で確定し、200ms 未満は追加しない。連打は手動入力のみで、AI 自動解析では生成しない。タイムラインでは両端が半円・中間が長方形の面で表示され、面をクリックで選択、右パネルで長さ（ms）を変更、「通常ヒットにする / 連打にする」で切替。他レベルとの 80ms 除外・同一レベルの最小間隔は区間全体に適用される |
| 音符を選択 / 追加選択 / 矩形選択 | クリック / `Shift`+クリック / 空き位置からドラッグ |
| 音符を移動 | ドラッグ（1ms 単位、スナップ有効時は拍・半拍・4分割・オンセットへ吸着、`Option` を押している間だけスナップ解除） |
| 再生ヘッドのスクラブ（停止中） | `←` `→` 短押しで 20ms、`Shift` で 100ms、`Option` で 1ms、`Shift+Option` で 500ms。300ms 以上の長押しで 60ms ごとに 20ms ずつ連続移動（約 0.33 倍速）し、移動先の音声片（40～100ms、左方向は逆再生）が原曲音量で鳴る。離すと直ちに停止。再生中は従来どおり 10ms / `Shift` で 100ms の移動 |
| 選択音符・サビ区間の移動 | `Cmd+←` `Cmd+→`（1ms）、`Cmd+Shift` で 10ms。他レベルの音符から 80ms 以内へは移動できない |
| 編集レーンの切替 | `↑` `↓` または左パネルの「編集」 |
| 全選択 / 削除 | `Cmd+A` / `Delete` `Backspace` |
| サビ区間を追加 / 移動 / 長さ変更 | サビストリップの空き位置をドラッグ / 区間をドラッグ / 端をドラッグ |
| シーク | ルーラーまたは波形をクリック・ドラッグ |
| ループ範囲 | ルーラーを `Shift`+ドラッグ、または選択中サビの「この区間をループ範囲にする」。`L` でループ切替 |
| 再生 / 一時停止 | `Space` |
| プレイテスト（Q または スペース / W / O / P で試奏） | `Cmd+P` または上部の「プレイテスト」。Esc で終了 |
| メトロノーム | `M` |
| ズーム | `+` / `-`、`Cmd`+ホイール。横スクロールはホイール |
| 新規 / 開く / 保存 / 名前を付けて保存 | `Cmd+N` / `Cmd+O` / `Cmd+S` / `Cmd+Shift+S` |
| Undo / Redo | `Cmd+Z` / `Cmd+Shift+Z` |
| AI自動解析 / 書き出し | `Cmd+R` / `Cmd+E` |

## 難易度間の音符重複ルール

- LEVEL 1～4 は独立した譜面で、異なるレベルの音符同士は時刻差が **80ms 以下**（境界を含む）なら重複とみなします。値は `packages/chart-format` の `CROSS_LEVEL_EXCLUSION_MS` で一元管理し、自動生成・手動追加・ドラッグ・数値入力・再生成・読み込み・書き出しがすべて同じ判定関数（`conflictsWithOtherLevel` / `findCrossLevelConflicts`）を使います。
- 自動生成は LEVEL 1 → 2 → 3 → 4 の順に行い、先に確定したレベルの音符から 80ms 以内の候補を除外して次点の音楽的候補を採用します。代替候補がない場合は音符数を減らし、右パネルと状態バーに「LEVEL n は、難易度間の重複を避けるため目標ヒット数に達しませんでした。生成数 / 目標」と表示します。
- 手動追加・移動で衝突する位置は確定せず、相手レベル・時刻・差・必要間隔を含む日本語エラーを表示します。ドラッグ中は衝突位置が赤で表示され、離すと最寄りの衝突しないスナップ候補へ移動するか元の位置へ戻します。拒否された操作は Undo 履歴に入りません。
- 衝突を含むプロジェクトや `chart.json` を読み込むと、「4レベルを再生成 / 衝突している音符だけ修復 / 読み取り専用で確認 / キャンセル」を選べます。修復は LEVEL 1 を優先して保持し、移動数・削除数・未修復数を表示し、1 回の Undo で戻せます。
- 難易度間衝突、同一レベルの同時刻・最小間隔違反、範囲外、非整数、レベル欠落がある状態ではゲーム用 JSON を書き出せません（全件を一覧表示）。書き出した `chart.json` には `generationRules`（`crossLevelExclusionMs: 80`, `levelPriority: [1,2,3,4]`, `crossLevelNotesAreExclusive: true`）が付きます。

## 手動確認手順

1. **MP3 読み込み → AI自動解析**: 「楽曲を読み込む…」で MP3 を選ぶ。左パネルにファイル名・形式・サイズ・長さ・サンプルレート・チャンネルが出て、波形レーンに波形が描かれる。「AI自動解析」を押すと下部に段階と割合が出る（キャンセル可）。完了後、BPM・拍・オンセット・サビ候補・4レベルの音符が生成される。壊れたファイル・0秒・30分超・500MB超は日本語のエラーになる。
2. **4レベルの確認と手修正**: LEVEL 1 → 4 の順に音符が増えること、L1 が主に小節頭・強い拍、L4 が裏拍・細分化を含むことを右パネルの「生成理由」で確認。レーンのダブルクリックで追加、ドラッグで移動、矩形選択 → `Delete` で一括削除。`Cmd+Z` / `Cmd+Shift+Z` で往復できる。最小間隔違反は右パネルに警告として出る（手編集では許可）。左パネルの密度・最小間隔を変え「譜面を再生成…」→「選択レベルだけ再生成」で手作業音符を残す／置き換えるを選ぶ。
3. **サビ区間の修正**: 検出されたサビはオレンジ、手動はマゼンタで波形上に表示。ストリップの空き位置をドラッグで追加、端のドラッグで長さ変更、本体のドラッグで移動、右パネルで数値入力と削除。変更後に「4難易度を再生成 / 選択レベルだけ再生成 / 既存音符を維持」を選ぶ。重なるサビを作ると結合を求められ、結合するまで保存・書き出しできない。
4. **再生・ループ・メトロノーム・試聴・スクラブ**: 停止中にタイムラインをクリックしてフォーカスし、`→` を短く押すと 20ms 進んで短い音が鳴る（`←` は逆再生音）。長押しで 300ms 後からゆっくり連続移動し、下部に「スクラブ中：時刻」（左は「逆方向スクラブ中」）が出る。離すと止まり、未保存表示や Undo は変わらない。入力欄にフォーカスがあるときは矢印がスクラブにならない。`Space` で再生、ルーラークリックでシーク。再生速度を 0.5x にしても右パネルの hitAtMs やタイムコードは原曲時間基準のまま。ループ範囲を `Shift`+ドラッグで作り、ループが繰り返されること、メトロノームが推定拍に、試聴音が編集中レベルの音符に同期することを確認。3つの音量が独立して効く。
5. **プロジェクト保存とクラッシュ復旧**: `Cmd+S` で `.rhythm-project.json` を保存すると上部が「保存済み」になり、Undo で保存位置へ戻っても「保存済み」に戻る。編集後 5 秒程度で下部に「自動保存しました」が出る。保存せずに強制終了（アクティビティモニタで終了など）し、再起動すると復旧ダイアログに日時と元プロジェクトが表示される。「復旧」すると元ファイルは上書きされず未保存状態で開く。音声ファイルを移動した場合は「音声を指定し直す…」で再指定する。
6. **ゲーム用フォルダ書き出し**: 「ゲーム用に書き出し…」で親フォルダを選ぶと `<楽曲ID>/chart.json` と `audio.mp3`（元ファイルのバイト列コピー）が作られ、書き出し直後にハッシュ・スキーマ・全時刻・全レベルが再検証される。同名フォルダがあれば「上書き / 別名 / キャンセル」を選ぶ。3000ms より前の音符や最小間隔違反は警告として表示される。
7. **書き出し再検証**: メニュー「ファイル > 書き出したフォルダを検証…」で書き出したフォルダを選ぶ。成功時は楽曲ID・BPM・各レベル音符数が表示され、現在のプロジェクトと同じ音声（SHA-256 一致）なら「この譜面を現在のプロジェクトへ読み込む」が使える。`chart.json` を手で壊す、音声を差し替える、`formatVersion` を 2 にすると日本語のエラーで拒否される。

## ネットワーク切断状態での確認

1. `npm run package:mac:editor` でパッケージを作る。
2. Wi‑Fi をオフにし、有線も外す。
3. `apps/chart-editor/release/mac-arm64/AutoBeats Chart Editor.app` を起動し、上記 1～7 をすべて行う。読み込み・解析・編集・保存・書き出し・再検証のすべてが外部通信なしで完了する（解析ワーカー・デコーダー・フォントはすべてアプリ内）。
4. `test/e2e/packaged.spec.ts` は同じパッケージ済みアプリを起動して MP3 読み込み・波形・解析ワーカーを自動確認する。

## 保存形式

- 編集用プロジェクト `*.rhythm-project.json`: `format: "autobeats-rhythm-project"`, `formatVersion: 1`。元音声は絶対パス参照（複製しない）で、サイズ・更新時刻・SHA-256 を保持し、開くときに再検証する。解析結果・BPM・拍・オンセット・サビ区間・4レベルの音符・レベル設定・表示状態を含む。書き込みは一時ファイル + rename。
- 自動保存: `~/Library/Application Support/@autobeats/chart-editor/autosave/`（`AUTOBEATS_USER_DATA` で変更可）。
- ゲーム用 `chart.json`: `packages/chart-format` の `kosen-rhythm-chart` formatVersion 1（ルート README を参照）。

## セキュリティ方針

- `contextIsolation: true` / `sandbox: true` / `nodeIntegration: false`。renderer は Node API に触れない。
- 音声は main process が検証したファイルだけをトークン付きのカスタムプロトコル `autobeats-media://` で配信し、renderer には絶対パスを渡さない。
- すべての IPC 引数は zod で検証し、ファイル書き込みはダイアログで選んだ場所と Application Support 配下に限る。
