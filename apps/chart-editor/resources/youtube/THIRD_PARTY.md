# Bundled tools

This application includes Python, yt-dlp and its dependencies, yt-dlp-ejs, FFmpeg (imageio-ffmpeg distribution), and Deno. See licenses/ for package notices and the bundled runtime's distribution metadata. PyInstaller builds the helper and permits redistribution under its bootloader exception.

- FFmpeg: https://ffmpeg.org/legal.html
- imageio-ffmpeg: https://github.com/imageio/imageio-ffmpeg
- Deno: https://github.com/denoland/deno

Build instructions and dependency versions are provided in the source archive.
