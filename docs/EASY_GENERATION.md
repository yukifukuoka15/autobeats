# やさしい追加譜面とLv4空欄への対応（v1.0.5）

- Lv4のノーツは0個で問題ありません。Lv4空欄の警告を削除しました。schema上のlevels.4は空配列として保持します。
- 書き出し完了の画面に「書き出しに成功」「Lv4が空でも利用可能」を明記します。
- 新規の追加譜面では密度と生成間隔をやさしい初期値にします。
- 「やさしく作り直す…」は、旧独立譜面にも使えます。追加分方式へ変更し、Lv1〜Lv3のやさしい設定を適用して生成します。
- 確認画面でLv1の自動生成分も作り直すかを選べます。手作業の打点を保持する設定が初期値です。通常の追加分再生成では既存Lv1は保持します。
- 自動生成する追加分は、下位レベルに対しても難易度別の生成間隔を空けます。
- 手作業の既存打点については生成用の推奨間隔を強制せず、統合後80msより離れていれば書き出せます。80ms以内の重複・接近は引き続き検証します。
- 設定変更と再生成は1回のUndoで戻せます。既存譜面へ設定を自動適用することはありません。
