# 追加譜面の作成

新規プロジェクトは追加譜面モードです。編集するのはLv1〜Lv3です。

- Lv1: 基本譜面。空なら解析後または生成操作で自動生成します。すでにあるLv1は置き換えません。
- Lv2: Lv1に足す打点だけを保持します。Lv1の打点をコピーしません。
- Lv3: Lv1＋Lv2に足す打点だけを保持します。

「Lv1からLv2・Lv3の追加分を生成…」で作成し、手直ししてください。手作業で修正した追加分を保持して再生成できます。
タイムラインの薄い破線は下位レベルの参考表示です。参考表示は選択・保存対象に含まれません。
打点と連打区間は、同じレベル・他レベルとも80msより離します。80msちょうどは配置できず、81msから配置できます。
Lv1を後で編集して追加分と近づいた場合は検証に表示します。検証後に追加分を移動・再生成してください。

保存・書き出しには追加分だけを含め、生成ルールにnoteMode: additiveを記録します。
別アプリでLv1、Lv1＋Lv2、Lv1＋Lv2＋Lv3として統合してください。このアプリのゲーム用書き出しは自動統合しません。
以前のプロジェクトは独立譜面モードとして読み込みます。「Lv1を土台に追加分だけ作成」を有効にすると追加譜面モードへ切り替えられます。切替だけでは既存ノーツを削除しません。
旧Lv4のデータは互換性のためファイル内に残しますが、画面には表示しません。
自動生成は編集用の候補です。太鼓の達人の既存譜面を再現・複製する機能ではありません。
