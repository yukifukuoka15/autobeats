# 手動確認手順

各項目の詳細な画面操作は [apps/chart-editor/README.md](../apps/chart-editor/README.md) と [apps/kosenfes-game/README.md](../apps/kosenfes-game/README.md) を参照してください。

## 1. 開発環境の起動

```bash
npm install
npm run fixtures
```

## 2. 譜面エディターだけを起動

```bash
npm run dev:editor
```

## 3. 高専祭ゲームアプリだけを起動

```bash
npm run dev:game
```

## 4. macOS 向けビルド

```bash
npm run build
npm run package:mac:editor
npm run package:mac:game
```

生成物: `apps/chart-editor/release/mac-arm64/AutoBeats Chart Editor.app`、`apps/kosenfes-game/release/mac-arm64/Kosenfes Game.app`

## 5. MP3 読み込みから AI 自動解析まで

1. エディターで「新規プロジェクト」→「楽曲を読み込む」→ MP3 を選択（テストなら `fixtures/generated/song.mp3`）。
2. 左パネルにファイル名、拡張子、サイズ、長さ、サンプルレート、チャンネル数が表示され、波形レーンに波形が出る。
3. 「AI自動解析」を押す。下部に段階と割合が表示され、「キャンセル」で中断できる。
4. 完了すると BPM、拍目盛り、サビ区間（半透明の色付き）、LEVEL 1～4 の音符が表示される。

## 6. 4 レベルの確認と手修正

- 左パネルでレベル表示を切り替え、各レーンの音符数が LEVEL 1 < 2 < 3 < 4 の傾向であることを確認する。
- レーンをダブルクリックして音符を追加、ドラッグで移動、Shift クリック・矩形で複数選択、Delete で削除。
- 右パネルで `hitAtMs` を数値入力、生成理由（beat / downbeat / onset など）と source（generated / manual）を確認する。
- Command+Z / Command+Shift+Z で往復できる。

## 7. サビ区間の修正

- 波形レーンの空き位置をドラッグして追加、区間本体をドラッグして移動、端をドラッグして長さ変更、Delete で削除。
- 変更後に「4難易度を再生成」「選択レベルだけ再生成」「既存音符を維持」を選ぶ。再生成は 1 回の Undo で戻る。
- 重なった区間は保存・書き出し前に結合を求められる。

## 8. 再生・ループ・メトロノーム・試聴

- Space で再生／一時停止。再生ヘッドをドラッグしてシーク。速度 0.5x / 0.75x / 1.0x / 1.25x を切り替えても音符の時刻は変わらない。
- ループ範囲を設定して繰り返し再生。メトロノームを ON にして拍と同期していることを確認。
- 試聴音を ON にして、表示中レベルの音符位置で短い音が鳴る。原曲・メトロノーム・試聴音の音量を個別に変えられる。

## 9. プロジェクト保存とクラッシュ復旧

1. Command+S（または名前を付けて保存）で `.rhythm-project.json` を保存する。
2. 編集後、保存せずにアプリを強制終了（アクティビティモニタまたは `kill -9`）する。
3. 再起動すると復旧候補（日時と元プロジェクト）が表示される。復旧を選ぶと直前の編集が戻る。元ファイルは上書きされていない。

## 10. ゲーム用フォルダ書き出し

1. 「書き出し」→ 検証結果を確認（エラーがあれば書き出せない。警告は表示のみ）。
2. 保存先を選ぶと `<trackId>/chart.json` と `<trackId>/audio.mp3` が作られる。既存フォルダがあれば上書き／別名／キャンセルを選ぶ。
3. 書き出し後に自動で再検証され、ハッシュ・音声存在・スキーマ・全時刻・全レベルの結果が表示される。

## 11. 高専祭アプリへのインポート

1. ゲームアプリの管理画面で「インポート」→ 書き出したフォルダ（または `chart.json`）を選ぶ。
2. 一覧に曲名、長さ、BPM、各レベル音符数、ハッシュ検証状態が出る。
3. 同じフォルダをもう一度インポートすると重複として登録されない。音声や譜面を変えて同じ trackId で書き出すと、置換か別 ID 登録を選べる。

## 12. 仮想デバイスを使った楽曲同期プレイ

1. 設定で楽曲、LEVEL、デバイス「仮想ボタン」を選ぶ。
2. 「スタート」→ 3 秒カウントダウン → 楽曲開始と同時に球が右から左へ流れる。
3. Space（または J / F）で押下。PERFECT / GOOD / BAD / MISS、EARLY / LATE、スコア、コンボ、LED 色が表示される。
4. 曲の終わりで結果画面へ移り、名前を登録するとその曲・レベル専用のランキングに載る。

## 13. 実物ボタンで確認すべき遅延補正

- 実機接続時は設定の「入力遅延補正」を -200～+200 ms（10 ms 刻み）で調整する。
- 120 BPM のクリック譜面（`fixtures/generated/click120.wav` から書き出し）を使い、拍どおりに押して EARLY が多ければ補正値を下げ、LATE が多ければ上げる。
- PERFECT 率が最大になる値を保存する。音声出力（内蔵スピーカー / 外部アンプ / Bluetooth）を変えたら再調整する。

## 14. パッケージ済みアプリをネットワーク切断状態で確認する

1. 手順 4 でパッケージを作る。
2. Wi-Fi をオフにし、有線 LAN も抜く（`networksetup -setairportpower en0 off`）。
3. `AutoBeats Chart Editor.app` を起動し、手順 5～10 を実行する。
4. `Kosenfes Game.app` を起動し、手順 11～12 を実行する。
5. いずれも外部通信なしで完了することを確認する（アプリは外部 URL を一切参照しない）。
