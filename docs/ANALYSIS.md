# ローカル音響解析の方式と限界

`packages/audio-analysis` は外部ライブラリ、ネイティブモジュール、WASM、Python ランタイムを使わない純粋 TypeScript 実装です。
Electron の renderer（Web Worker）でも Node（テスト）でも同じコードが動きます。

## パイプライン（`analyzeAudio`）

| 段階 | 方式 |
| --- | --- |
| デコード | エディター renderer で Chromium 内蔵の `AudioContext.decodeAudioData`（MP3 / WAV / M4A / OGG）。外部依存なし |
| 前処理 | チャンネル平均でモノラル化 → 箱型平均＋線形補間で 22,050 Hz へ |
| フレーム特徴 | 中心基準 STFT（窓 1024、ホップ 256 ≒ 11.6 ms、Hann）。40 帯域の対数エネルギー、RMS、低域（<150 Hz）、スペクトル重心 |
| chroma | 別パスで窓 4096、ホップ 1024。55～4200 Hz を 12 音名へ集約し L2 正規化 |
| オンセット | superflux 風スペクトルフラックス（前フレーム隣接帯域の最大との半波整流差）→ 局所平均除去 → 99.5 パーセンタイル正規化 → 適応閾値ピーク検出（最小間隔 50 ms） |
| テンポ | 12 秒窓のオンセット包絡自己相関を全窓で合算（テンポグラム集約）、118 BPM 中心の対数正規事前分布、倍・半テンポ整合、放物線補間 |
| 拍追跡 | Ellis (2007) の動的計画法（周期からの逸脱に対数二乗ペナルティ、tightness 100）。拍位置は包絡の放物線補間で小数フレーム精度、BPM は拍時刻の線形回帰で精密化 |
| 小節頭 | 4/4 前提。各拍の「低域の立ち上がり＋オンセット強度＋和声変化」を 4 位相で集計し最大の位相を小節頭とする |
| 曲構成 | 拍同期特徴（1 小節平滑化 chroma 12 次元＋標準化した音量・低域・重心・オンセット 4 次元）のガウス RBF 自己類似行列 → Foote のチェッカーボード・ノベルティ（半幅 ≒ 4 秒）→ ピークを小節頭へ吸着（最小区間 5 秒） |
| サビ候補 | 区間の反復性（他区間との対角類似度上位 2 件平均）0.45、エネルギー 0.35、明るさ 0.1、位置・長さ事前分布を合成。類似度 0.72 以上で同一クラスタとし、最高スコアのクラスタの各出現をサビ候補（最大 6）にする。信頼度 0.05～0.99 |
| 無音 | RMS が最大値の 2% 未満の先頭・末尾を無音区間とし、拍・オンセット・音符を置かない |

## 4難易度生成（`generateLevel`）

共有候補集合 = 小節頭（基本重み 1.0）、拍（0.75）、裏拍（0.45）、4 分割（0.4）、グリッドに乗らないオンセット（0.6）。
近接（±70 ms）オンセットでグリッド候補を強化し、スナップ強度に応じてオンセット位置とグリッド位置の間に置きます。
`score = base × (0.4 + 0.6 × オンセット強度)`。

| レベル | 採用種別（通常） | サビで追加 | 小節上限 | 最小間隔 | サビ倍率 |
| --- | --- | --- | --- | --- | --- |
| 1 | 小節頭・拍・オンセット | なし（閾値のみ下げる） | 2 | 600 ms | 1.35 |
| 2 | 小節頭・拍・オンセット | 裏拍 | 4 | 400 ms | 1.45 |
| 3 | ＋裏拍 | 4 分割 | 6 | 280 ms | 1.55 |
| 4 | ＋4 分割 | なし | 8 | 220 ms | 1.65 |

閾値 = `0.75 − 0.5 × 密度`。サビ区間では閾値を倍率で割り、小節上限も倍率倍にします。スコア降順の貪欲採用で最小間隔と小節上限を守り、同時刻は重複させません。手作業音符は保持（生成音符は手作業音符との最小間隔を守る）または置換を選べます。

## 実測（合成音、Apple Silicon、Node 26）

| 入力 | 解析時間 | 結果 |
| --- | --- | --- |
| 120 BPM クリック 20 秒 | < 0.1 秒 | BPM 誤差 < 1、拍位置 90% 以上が ±40 ms |
| 構造付き合成曲 92 秒（3 サビ） | 0.3 秒 | 3/3 のサビを境界 ±0.5 秒で検出 |
| 5 分合成曲 | 1.1 秒 | — |
| 29 分合成曲 | 6.5 秒 | メモリ RSS 約 780 MB（PCM 込み） |

## 既知の限界

- テンポが途中で変わる曲、ルバート、変拍子（3/4、5/4 等）では拍・小節頭がずれます。4/4 固定です。
- 倍・半テンポの曖昧さ（例: 70 BPM と 140 BPM）は事前分布で判断するため、意図と逆になることがあります。
- サビ推定は「反復していて大きく明るい区間」を選ぶ発見的手法です。ギターソロ、繰り返しのない構成、ライブ録音、アカペラでは誤検出・未検出があります。候補は必ず手修正を前提にしてください。
- 1 窓 11.6 ms の時間分解能のため、オンセット位置は ±10～20 ms 程度の誤差を持ちます。
- 解析結果の精度を 100% と表示しないでください。UI の「AI自動解析」はローカル音響解析の呼称です。
